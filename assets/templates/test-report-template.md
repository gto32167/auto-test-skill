### 2.1 质量门禁说明与状态

> 门禁是测试流程阶段之间的自动质量校验点。`pass` 表示测试产物完整、版本一致、结果与证据符合规则，并允许进入下一阶段；不表示产品功能全部通过。产品质量结论必须以本报告的通过、失败、阻塞和未执行统计为准。

| 门禁 | 检查重点 | `pass` 的含义 | 状态 |
| :--- | :--- | :--- | :--- |
| 用例设计门禁（07_case_design_gate.json） | 需求覆盖、测试点与用例映射、优先级、单断言和语义契约 | 最终用例源可用于模板和计划 |  |
| 执行计划门禁（10_execution_plan_gate.json） | 计划与最终用例的版本、通道、核心步骤和观察项一致 | 可以启动正式执行 |  |
| 执行结果门禁（12_execution_gate.json） | 重试、轨迹、观察值、证据、判定和汇总一致 | 可以生成执行回填版 |  |
| 最终交付门禁（19_delivery_gate.json） | 回填行数、ID、状态、实际结果、文件结构和查看器可读性 | 交付物完整，可以生成正式报告 |  |

逐用例的执行状态、实际结果、产出数据和证据索引以 `18_测试用例_执行回填版.xlsx` 为准。本报告不重复列出通过、失败或阻塞用例摘要，只保留总体结论、缺陷和风险。
