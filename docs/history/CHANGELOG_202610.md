# 2026 年 10 月变更记录

## v4.0.0（2026-10-13）：当前 auto-test-skill 增量整合 V3 能力

背景：本次将 V3 来源方案强化的生成质量和资源核算能力整合到当前框架，并发布为 v4.0.0；当前库独有 Excel 导入规范化、人工准备门禁和原始用例聚合，不能直接覆盖。

变更：移入质量契约 1.0、独立覆盖签名与 N_min、原文辅助扫描器、保守迁移工具和工作流资源账本；runner、运行副本、计划、结果、报告同步账本。保留原有 XLSX 与人工分流能力。补充 XLSX 基线来源契约，修复权限事实静默遗漏、缺数据处理、确认时间、smoke 标签绕过、报告固定项目描述与最终账本绑定。按 N_min 消除用例数量膨胀，修正显式 L2 范围与 risk-first 缺档说明。人工准备继续保留，但移除人工 skip：准备未完成时整个批次在执行前停止，必须完成准备后 run 或明确移交 manual。同步模板、启动提示词、阶段规则和发布检查单。

验证：升级后全套脚本回归 140 passed；出厂模板严格设计门禁与强制资源核算计划门禁通过，N_min=3，最终 3 条并生成非空 Excel；技能校验和 Python/YAML 静态解析通过。测试使用隔离夹具及模拟证据，未做真实业务 UI 回归。

说明：v4.0.0 只修改本地框架，未全局安装、提交、推送或部署。来源 V3 的 9 月历史记录已单独标记出处，不代表本次验证。
